# Based Quake Installer

Installs unezQuake and FTE with a set of classic QuakeWorld mods, binds already set up.

## Features

- unezQuake and FTE, each in its own folder, with the Quake shareware data
- Ten classic mods: Team Fortress, Thunderwalker CTF, Rocket Arena, PainKeep, Headhunters, AirQuake, Future vs Fantasy, Quake Rally, Get Rich Quake, Rune Quake
- Key binds for every client and mod: click a box, press a key
- Server browser list for unezQuake
- Check for updates
- Updates itself (Update installer)
- Windows 10/11 x64 and Debian-based Linux

## Download

Get the latest [release](https://github.com/USDQC/based-quake-installer/releases/latest). Windows: unzip `BasedQuakeInstaller-windows-x64.zip` and run `BasedQuakeInstaller.exe`. Linux: `sudo apt install ./based-quake-installer_*_all.deb`. Details are in `Based-Quake-Installer-Manual.pdf`.
