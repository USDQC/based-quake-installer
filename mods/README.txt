Mods download from the USDQC Google Drive (one <gamedir>.zip each, sha256-checked against
mods.json) and unzip into each client's gamedir. This folder is not searched.

Install a zip you already downloaded (still sha256-checked):
  installer_cli.py --mods-only --mods fortress --mod-file fortress=path\to\fortress.zip

FTE only: airquake, fvf, rally. Both clients: painkeep, hh, fortress, ctf, arena, grq.
Rune Quake: server-side, binds only. Registered Quake mods need your own pak1.pak in id1.
